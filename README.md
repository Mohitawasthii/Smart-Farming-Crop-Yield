## 📌 Project Overview

The **Smart Farming Crop Yield Analytics Dashboard** is an interactive **Tableau** project designed to analyze crop production using agricultural and environmental data. The dashboard provides insights into crop yield, weather conditions, soil quality, fertilizer usage, irrigation methods, and crop diseases to support data-driven farming decisions and sustainable agriculture.

## 🎯 Project Objectives

- Analyze crop yield across different crop types.
- Monitor environmental factors affecting production.
- Evaluate fertilizer and irrigation effectiveness.
- Assess crop disease impact on yield.
- Compare regional crop performance.
- Build an interactive dashboard for agricultural insights.

## 📂 Dataset Features

The dataset includes:

- Crop Type
- Yield (Kg/Hectare)
- Temperature
- Rainfall
- Humidity
- Soil Moisture
- Soil pH
- NDVI Index
- Fertilizer Type
- Irrigation Method
- Crop Disease Status

## 📈 Key Insights

- Soybean records the highest average crop yield.
- Organic fertilizer performs slightly better than mixed fertilizer.
- Drip irrigation delivers the highest crop productivity.
- June records the peak harvesting period.
- Mild crop disease shows minimal impact on yield compared to moderate disease.
- Soil moisture, rainfall, and temperature remain within optimal ranges for healthy crop growth.
